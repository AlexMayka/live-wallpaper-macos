# Живые обои для macOS

Нативное приложение в строке меню. Зацикливает локальное видео или показывает фото на рабочем столе. Для встроенного дисплея и каждого подключённого монитора можно выбрать отдельный файл, масштаб и громкость.

## Сборка и запуск

Для сборки нужны macOS, Swift 6 и инструменты командной строки Xcode. Минимальная версия для запуска — macOS 14. Сборка выполняется для архитектуры текущего Mac. Если инструменты ещё не установлены, запустите `xcode-select --install`.

Соберите и откройте приложение из корня репозитория.

```sh
./build.sh
open "dist/Живые обои.app"
```

При первом запуске чистой сборки показываются системные обои. Свой файл можно выбрать в окне приложения. Чтобы добавить собственное видео по умолчанию в пакет приложения, передайте путь к MP4 или MOV при сборке.

```sh
./build.sh "/полный/путь/к/обоям.mp4"
```

Сборка создаёт локально подписанное приложение в каталоге `dist/`. Используйте свои видео и фото или материалы, на которые у вас есть права. Храните личные медиафайлы отдельно от репозитория.

## Настройка обоев

1. Откройте **«Настройки обоев…»** через значок приложения в строке меню.
2. Выберите дисплей слева и нажмите **«Выбрать файл…»**. Подойдут, например, видео MP4 или MOV, изображения PNG или JPEG. Возможность воспроизведения видео зависит от его кодека.
3. Выберите масштаб и, если в видео есть звуковая дорожка, настройте звук.

| Настройка | Что делает |
| --- | --- |
| **Обои приложения** | Переключает выбранный дисплей между обоями приложения и системными обоями. |
| **Заполнить** | Покрывает весь дисплей с сохранением пропорций. Часть кадра может обрезаться. |
| **Вписать** | Показывает кадр целиком. Если пропорции различаются, по краям остаются поля. |
| **Звук и громкость** | Управляет звуковой дорожкой обоев выбранного дисплея. По умолчанию звук выключен. Все дорожки воспроизводятся через выбранное в macOS устройство вывода. |
| **Вернуть обои macOS** | Сбрасывает выбор файла для дисплея. Если при сборке добавлено встроенное видео, кнопка вернёт его. |
| **На все экраны** | Применяет выбранный файл ко всем подключённым дисплеям, сохраняя настройки масштаба, звука и включения обоев для каждого из них. |
| **Пауза на всех** | Приостанавливает все видеообои на текущий сеанс. Возобновить их можно в окне настроек или из строки меню. |
| **Запуск при входе** | Регистрирует приложение в объектах входа macOS. Если система попросит подтверждение, проверьте настройки объектов входа. |

В окне настроек предпросмотр показывает фотографию или кадр из видео. Когда дисплеи засыпают или сеанс пользователя становится неактивным, приложение ставит видео на паузу. После пробуждения и возврата в сеанс оно продолжает воспроизведение, если общая пауза выключена.

Файл и параметры сохраняются по идентификатору дисплея. При следующем запуске приложения или повторном подключении монитора настройки восстанавливаются. Приложение хранит ссылки на исходные файлы. Если файл переехал и приложение потеряло к нему доступ, выберите его снова. Закрытие окна настроек оставляет обои в работе. Чтобы завершить приложение, выберите **«Выключить живые обои»** в строке меню.

## Устройство проекта

| Файл | Назначение |
| --- | --- |
| [`Source/LiveWallpaperApp.swift`](Source/LiveWallpaperApp.swift) | Запуск приложения, окно настроек, меню и события macOS. |
| [`Source/SettingsView.swift`](Source/SettingsView.swift) | Интерфейс настроек на SwiftUI. |
| [`Source/WallpaperManager.swift`](Source/WallpaperManager.swift) | Список дисплеев, выбор файлов, сохранение настроек и управление воспроизведением. |
| [`Source/WallpaperEngine.swift`](Source/WallpaperEngine.swift) | Загрузка фото и видео, предпросмотр и отображение обоев. |
| [`Info.plist`](Info.plist) и [`Resources/`](Resources/) | Параметры пакета приложения и его значок. |
| [`build.sh`](build.sh) | Компиляция Swift, сборка пакета и локальная подпись. |

AppKit размещает отдельное окно обоев на каждом дисплее под значками Finder. Окно пропускает клики, поэтому рабочим столом можно пользоваться как обычно. AVFoundation воспроизводит видео по кругу и управляет его звуком. ImageIO загружает фотографии. Настройки хранятся в `UserDefaults`, ссылки на файлы — в виде закладок macOS.

## Проверка после сборки

- Установите видео со звуком на один дисплей и фото на другой. Проверьте, что громкость доступна только для видео со звуковой дорожкой.
- Переключите масштаб на одном дисплее, поставьте видео на общую паузу и возобновите его.
- Перезапустите приложение и проверьте, что файлы, масштаб и громкость сохранились для соответствующих дисплеев.
- Выключите **«Обои приложения»** на одном дисплее. На нём должен появиться системный фон.
